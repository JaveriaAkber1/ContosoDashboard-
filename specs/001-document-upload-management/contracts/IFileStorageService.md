# Contract: IFileStorageService

Storage abstraction required by Constitution Principle II. The local implementation (`LocalFileStorageService`) is the only one built in this feature; a future `AzureBlobStorageService` must satisfy the same interface with no caller changes.

```csharp
public interface IFileStorageService
{
    Task<string> UploadAsync(Stream fileStream, string storagePath, string contentType);

    Task DeleteAsync(string storagePath);

    Task<Stream> DownloadAsync(string storagePath);

    Task<string> GetUrlAsync(string storagePath, TimeSpan expiration);
}
```

## Method contracts

### `UploadAsync(Stream fileStream, string storagePath, string contentType)`
- **Pre-condition**: `storagePath` is already a fully-formed, unique, GUID-based relative path (e.g. `{userId}/{projectId-or-"personal"}/{guid}.{ext}`) generated by the caller (`DocumentService`) — this method does not invent or validate uniqueness itself.
- **Behavior (local impl)**: Ensures the directory structure under the configured root exists, writes `fileStream` to `{RootPath}/{storagePath}` using `System.IO.File`/`FileStream`, never overwriting an existing file at that path (collision = caller bug, since paths are GUID-based).
- **Returns**: The same `storagePath` (or a storage-specific identifier) for persistence on the `Document` row.
- **Failure modes**: Throws `IOException`/`UnauthorizedAccessException` on disk failure; caller (`DocumentService.UploadAsync`) catches and ensures no `Document` row is created (FR-009).

### `DeleteAsync(string storagePath)`
- Idempotent: deleting a path that does not exist is not an error (supports the orphan-cleanup path in `UploadAsync`'s failure handling, and supports `DocumentService.DeleteAsync`/`ReplaceFileAsync` cleanup).

### `DownloadAsync(string storagePath)`
- Returns a readable `Stream` over the file content. Caller (`DocumentDownload` Razor Page) is responsible for all authorization checks before calling this — this method performs no authorization itself (it operates purely on a trusted, already-validated path).

### `GetUrlAsync(string storagePath, TimeSpan expiration)`
- For the local implementation, this is expected to return an internal application route (e.g., the `DocumentDownload` Razor Page URL) rather than a directly-browsable file-system URL, since local files are never web-accessible (FR-008). A future Azure implementation would return a SAS URL with the given expiration — the interface shape is deliberately pre-built for that migration even though the local implementation doesn't need true time-limited URLs.
